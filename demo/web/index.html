Neural Flux-Conservative PDE Solver

A convolutional network predicts fluxes at cell interfaces instead of the next state directly, so mass conservation is exact by construction. Trained with multi-step rollout + noise injection, it takes several times the classically CFL-limited timestep while staying competitive with high-order finite-volume solvers on accuracy per unit of wall-clock cost. See the repo and write-up for details.
